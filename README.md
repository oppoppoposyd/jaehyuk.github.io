# 내 블로그 — 시작 안내

흰 종이 · 반투명 빨간 줄 하나 · 반투명 검정 명조체로 만든 블로그입니다.
GitHub Pages에 올리면 무료로 공개되고, 구글에 검색되도록 설정(SEO·사이트맵)이 이미 들어 있습니다.

---

## 1. GitHub에 올리기 (처음 한 번)

1. https://github.com 에 가입·로그인합니다.
2. 오른쪽 위 **+ → New repository** 를 누릅니다.
3. 저장소 이름을 **`내깃허브아이디.github.io`** 로 정확히 입력합니다. (예: 아이디가 `jaehyuk`이면 `jaehyuk.github.io`)
   - **Public** 으로 두고 **Create repository** 를 누릅니다.
4. 만들어진 화면에서 **uploading an existing file** 을 눌러, 이 폴더 **안의 모든 파일과 폴더**를 끌어다 놓고 **Commit changes** 를 누릅니다.
   - 폴더 째가 아니라 *내용물*을 올려야 합니다. (`_config.yml`이 저장소 맨 위에 보여야 합니다.)
   - `.pages.yml` 같은 점(.)으로 시작하는 파일이 안 끌려오면, 압축을 풀지 않고 파일 탐색기에서 "숨김 파일 표시"를 켠 뒤 올리세요.
5. 저장소 **Settings → Pages** 로 가서 **Source: Deploy from a branch**, **Branch: main / (root)** 를 고르고 **Save**.
6. 1~3분 뒤 `https://내깃허브아이디.github.io` 에 블로그가 뜹니다.

## 2. 내 정보로 바꾸기

저장소에서 `_config.yml` 을 열고 연필 아이콘(✏️)을 눌러, **★ 표시된 곳**만 고칩니다.

| 항목 | 설명 |
|---|---|
| `title` | 블로그 이름 |
| `description` | 구글 검색 결과에 보일 소개문 |
| `author` | 필명 |
| `url` | `https://내깃허브아이디.github.io` |

고친 뒤 **Commit changes**. (`url`은 구글 검색에 중요하니 꼭 맞게 넣으세요.)

## 3. 글 쓰고 고치기 — 쉬운 관리자

코드를 만질 필요 없이, 워드프로세서처럼 쓰는 관리자 화면입니다.

1. https://app.pagescms.org 접속 → **GitHub로 로그인**
2. 내 저장소 선택
3. 왼쪽에서 **글** → **새로 만들기**
   - 제목, 날짜, **검색 결과에 보일 한 줄 소개**, 본문을 채우고 **저장**
   - 본문에서 굵게·기울임·인용·제목·이미지 삽입을 버튼으로 할 수 있습니다.
4. **소개 페이지** 메뉴에서 `/about/` 페이지를 고칩니다.

저장하면 1~2분 안에 블로그에 반영됩니다. 샘플 글 "첫 번째 글"은 관리자에서 지우거나 덮어쓰세요.

> 관리자가 막히면 GitHub 저장소의 `_posts` 폴더에서 직접 파일을 추가·수정해도 같은 결과입니다.

## 4. 구글 검색에 노출시키기

블로그를 올리기만 해서는 구글이 바로 알지 못합니다. 아래를 한 번만 해두세요.

1. https://search.google.com/search-console 접속 → **속성 추가 → URL 접두어** → `https://내깃허브아이디.github.io`
2. 소유권 확인 방법에서 **HTML 태그**를 고르고 나오는 코드를 복사합니다.
   - 예: `<meta name="google-site-verification" content="`**`abc123...`**`" />` 에서 굵은 부분만 복사
3. `_config.yml` 에서 아래 세 줄의 앞 `#` 을 지우고 코드를 넣은 뒤 Commit:
   ```yaml
   webmaster_verifications:
     google: "abc123..."
   ```
4. 1~2분 뒤 서치콘솔로 돌아가 **확인** 을 누릅니다.
5. 왼쪽 **Sitemaps** 에 `sitemap.xml` 을 입력하고 **제출**.
6. **URL 검사**에 블로그 주소를 넣고 **색인 생성 요청**.

색인되는 데는 보통 며칠~몇 주가 걸립니다. 처음엔 안 보여도 정상입니다.

### 검색에 잘 걸리는 글쓰기 팁
- **제목**에 사람들이 검색할 말이 들어가게 쓰기
- 글마다 **한 줄 소개**(관리자의 "검색 결과에 보일 한 줄 소개")를 꼭 채우기 — 구글 결과 설명으로 쓰입니다
- 꾸준히 올리기

## 5. 분위기 바꾸고 싶을 때

`assets/css/style.css` 맨 위의 변수만 고치면 됩니다.

```css
--ink:  rgba(0,0,0,0.74);     /* 글자 검정의 투명도 */
--red:  rgba(214,31,48,0.55); /* 빨간 줄의 색·투명도 */
--haze: #e9e8e5;              /* 흰 종이 바깥 배경 (글로우가 번지는 색) */
```

## 파일 구성

```
_config.yml        블로그 기본 설정 (★)
.pages.yml         관리자 화면 설정
index.html         글 목록 (첫 화면)
about.md           소개 페이지
_posts/            글이 저장되는 곳
_layouts/          페이지 틀
assets/css/        디자인
404.html           없는 페이지 안내
robots.txt         검색엔진 안내
```
